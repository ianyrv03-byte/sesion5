# SafeRoute

Proyecto integrador – Taller 5: Construcción de Software (TDD, Git, Pull Request).

## Funcionalidad
Como sistema de distribución, quiero conocer el peso total de un envío para verificar que pueda ser transportado por un vehículo.

## Ejecutar
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pytest
```

## Flujo de trabajo
Rama `feature/calculo-peso-envio`: commits RED -> GREEN -> REFACTOR, luego Pull Request revisado por un compañero.
